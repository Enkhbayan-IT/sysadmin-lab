# Windows Server 2025 System Administration Lab

A hands-on Windows Server 2025 lab environment built to practice core System Administration skills. This repository documents each lab with configuration steps, screenshots, and technical notes.

The goal of this project is to develop practical experience with Windows Server administration and build a portfolio that demonstrates real-world infrastructure skills.

# Lab Structure

## 01. Windows Server Installation

Topics covered:

* Installing Windows Server 2025
* Initial login
* Administrator account configuration
* Verifying the installation

---

## 02. Initial Server Configuration

Topics covered:

* Changing the computer name
* Configuring a static IP address
* Changing the time zone to Stockholm
* Disabling Internet Explorer Enhanced Security Configuration
* Preparing the server for additional roles

---

## 03. Active Directory Domain Services

Topics covered:

* Installing the AD DS role
* Promoting the server to a Domain Controller
* Creating a new forest
* Configuring the domain
* Verifying Active Directory installation

---

## 04. DNS Server

Topics covered:

* Installing the DNS Server role
* Verifying DNS functionality
* Exploring DNS Manager
* Understanding Forward Lookup Zones
* Basic DNS administration

---

## 05. DNS Records

Topics covered:

* Creating A Records
* Creating CNAME Records
* Creating PTR Records
* Testing DNS name resolution
* Understanding forward and reverse lookup zones
