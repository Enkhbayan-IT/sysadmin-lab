# Windows Server & System Administration Labs

This repository documents my hands-on labs for Windows Server, Active Directory, DNS, DHCP, Group Policy, and basic system administration.

## Lab Environment

- Hypervisor: VMware Workstation / VirtualBox
- Server OS: Windows Server 2025
- Client OS: Windows 10/11
- Domain: lab.local
- Network: Private NAT / Host-only lab network

## Skills Practiced

- Windows Server installation and configuration
- Static IP configuration
- Active Directory Domain Services
- DNS server configuration
- A, CNAME, PTR records
- DHCP scopes and reservations
- Group Policy basics
- User and group management
- Troubleshooting network and domain issues
