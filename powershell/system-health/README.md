# PowerShell System Health Check

A PowerShell system administration script that collects basic Windows system information, displays disk usage and service status, and warns when available disk space is low.

This project is part of my **PowerShell / Windows System Administration Lab**.

## Features

The script performs the following tasks:

* Retrieves the computer name
* Retrieves the currently logged-in user
* Displays the report date and time
* Retrieves operating system information
* Displays the last reboot time
* Calculates total system memory in GB
* Retrieves local file system drives
* Calculates used and free disk space
* Retrieves Windows service status
* Displays Running and Stopped services
* Checks available disk space
* Generates a warning when disk free space is low
* Displays a report summary when the script completes

## Disk Space Check

The script checks the available space of each detected file system drive.

For example:

```text
Drive C Free Space: 439.12 GB
Drive D Free Space: 9.75 GB ***Low Disk Space***
```

In this test, drive `D:` had only **9.75 GB** of free space, so the script generated a low disk space warning.

This demonstrates the use of conditional logic to detect a potential system health issue rather than only displaying system information.

## Service Status

The script retrieves Windows services and displays their current status.

Example:


The full script output may contain a large number of both `Running` and `Stopped` services depending on the Windows system.

## How to Run

Clone the repository or download the script.

Open PowerShell and navigate to the script directory:

```powershell
cd .\powershell\system-health
```

Run the script:

```powershell
.\Get-SystemInfo.ps1
```

The script will collect system information and display the health report directly in the PowerShell terminal.
